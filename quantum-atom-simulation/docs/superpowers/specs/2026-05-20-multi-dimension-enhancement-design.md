# Quantum Atom Simulation 多维度增强设计

- 日期：2026-05-20
- 版本：0.3.1 → 0.4.0（计划）
- 范围：教学体验(A)、物理能力(B)、工程产品化(C)、可视化渲染(D)
- 前提：跳过跨平台推进，C 维度不含 Linux/macOS 适配

---

## 1. 总览

本项目从当前 v0.3.1 出发，沿四个维度依次推进增强。每个维度产出可独立验证的交付物。

### 推进顺序

```
C（交互直观性）→ B（场景丰富度）→ A（学习路径）→ B（物理深化）→ D（可视化提升）
```

C 与 A 共享 UI 层改动，因此先 C 后 A 可避免返工。B 分为两部分：场景数据扩展可在 C 之后独立进行，物理模块深化在最后。D 涉及渲染底层，放在最后减少对其他维度的影响。

### 2.2 快捷控制面板重新组织

采用折叠分组结构：

```
▼ 元素与模式 （默认展开）
  [元素选择器：下拉列表 Z=1 氢(H)]
  [模型切换：●玻尔 ○薛定谔云 ○波粒演示 ○对比]
  [近似切换：●严格氢样 ○多电子近似]

▼ 场景预设 （默认展开）
  卡片式场景浏览器，见维度 B 设计

▼ 自动演示 （默认展开，含播放/暂停/进度条）

▶ 云与外观 （默认折叠）
  点云数量、体分辨率、范围倍率、相位着色、LOD、色图选择

▶ 跃迁与光谱 （默认折叠）
  初态/末态量子数、选择规则、精细结构/Zeeamn/Stark/Hyperfine 开关

▶ 高阶物理 （默认折叠）
  平均场参数、关联参数、动力学参数、核过程设置

─────────────────────────
[+ 展开高级面板]
```

- 元素选择器从数字输入改为下拉列表 `Z=原子序数 元素名(符号)`
- 「云与外观」「跃迁与光谱」「高阶物理」三组默认折叠

### 2.3 场景 HUD 浮层

3D 场景视口右上角半透明浮层：

- 始终显示：元素名 + 模型名
- 状态色条：绿色（严格氢样/可靠）、黄色（多电子近似/教学级）、红色（配置冲突/警告）
- hover 时扩展显示完整近似警告文本
- 自动演示中增加底部进度条
- 核过程动画时显示模式标签

### 2.4 颜色编码

- Physics 面板验证表格：按状态着色行（绿=参考吻合 / 黄=基础检查 / 灰=未验证）
- 方法标签列表：每条前带 Tier 层级徽章 T0-T5
- 动画分类说明：顶部 callout 样式突出

### 2.5 学习指引面板

替换 Help 面板的纯操作列表为：

1. 「当前你在看什么」：根据模型和元素动态生成概念说明（1-2 句）
2. 「关键看点」：提取 2-4 个当前场景最值得关注的指标
3. 「操作提示」：保留键盘/鼠标操作指南

## 4. 维度 A：学习路径

### 4.1 四条学习路径

**路径一：原子结构入门**

| 步骤 | 场景 | 学习目标 |
|---|---|---|
| 1 | 氢原子玻尔轨道 | 理解轨道量子化 |
| 2 | 氢原子薛定谔概率云 | 从轨道到概率云 |
| 3 | 氢原子叠加态 | 量子叠加态概念 |
| 4 | He+ 离子相位云 | 类氢体系缩放 |

**路径二：光谱探秘**

| 步骤 | 场景 | 学习目标 |
|---|---|---|
| 1 | 氢原子谱线系 | 跃迁与光子能量 |
| 2 | 精细结构拆分 | 自旋-轨道耦合 |
| 3 | Zeeman 效应 | 外磁场下的谱线 |

**路径三：多电子原子**

| 步骤 | 场景 | 学习目标 |
|---|---|---|
| 1 | 锂到氖组态趋势 | Aufbau 填充规则 |
| 2 | 钠到氩周期趋势 | Z_eff 屏蔽效应 |
| 3 | 氖原子多电子近似 | 有效核电荷 |

**路径四：核物理入门**

| 步骤 | 场景 | 学习目标 |
|---|---|---|
| 1 | 粒子展示 | 认识基本粒子 |
| 2 | D-T 聚变 | 聚变截面与条件 |
| 3 | U-235 裂变 | 裂变与链式反应 |
| 4 | α 衰变 | 衰变统计规律 |

### 4.2 学习模式 UI

快捷控制面板顶部增加学习模式入口：

- 下拉选择学习路径
- 选中后显示：路径名、步骤计数 N/M、进度条
- 每步显示引导文字（概念说明 + 操作指引）
- Inspector 只暴露当前步骤允许的参数，其余隐藏/禁用
- 提供「上一步」「下一步」导航按钮
- 学习模式下关闭场景预设区，替换为路径相关控件

### 4.3 参数锁定机制

`SimulationState` 新增 `LearningParams` 结构：

```cpp
struct LearningParams {
    bool enabled = false;
    int pathIndex = 0;
    int stepIndex = 0;
    std::vector<std::string> lockedParamKeys;
    std::string guideText;
};
```

UI 在渲染参数控件时检查 `lockedParamKeys`，被锁定的参数显示为灰色禁用态。

## 5. 维度 B（续）：物理能力深化

### 5.1 参考谱线目录扩展

| 扩展 | 当前 | 目标 |
|---|---|---|
| 氢样离子谱线 | H + He+ 各 3-4 条 | H, He+, Li²+, Be³+, B⁴+ 各 5+ 条 |
| 轻元素参考线 | 无 | Z=3-18 关键可见光谱线，每元素 2-4 条 |
| 同位素锚点 | isotopes.json 基本数据 | 补充教学常用同位素的核自旋、磁矩、丰度 |

数据来源：NIST ASD 公开数据手动整理，存入 `reference_catalog.json` 和 `isotopes.json`。

### 5.2 Tier 2 平均场增强

- 初始猜测改进：从 Thomas-Fermi 近似生成初始密度分布
- 线性混合策略：`ρ_new = α·ρ_old + (1-α)·ρ_new`，α 默认 0.3
- 收敛诊断输出：在 SCF 残差图上标注混合系数和振荡警告
- 混合系数在 GUI 中可调（0.1-0.9）

### 5.3 Tier 3 谱学修正细化

- Zeeman：增加 Paschen-Back 过渡区的定性展示（强场极限与弱场极限对比）
- Stark：扩展到氢 n=2 态的二次 Stark 4x4 矩阵对角化
- Hyperfine：F 总量子数标记 + 超精细能级分裂图示

### 5.4 参考数据校验

- 批量回归：对所有 `reference_catalog.json` 中的谱线运行解析能级预测
- 偏差 > 1% 的标记 warning
- 验证报告中新增「数据质量」章节

## 6. 维度 D：可视化与渲染提升

### 6.1 场景截图导出

- 快捷键 `Ctrl+S`：保存 3D 视口到 PNG
- 保存路径：`docs/reports/screenshots/`，文件名含时间戳
- 实现：`glReadPixels` → stb_image_write
- 右键菜单入口 + Inspector 底部按钮

### 6.2 图表专业化

- 图例：多系列图表增加可交互图例
- 坐标轴标签：X/Y 轴显示单位（nm, eV, Bohr 等）
- 十字光标：hover 时十字准线 + 数值浮窗
- 主/次网格线可选
- 右键菜单：导出 CSV / 重置视图 / 适配窗口

### 6.3 概率云渲染增强

- 色图切换：热力图、蓝白、彩虹、灰度四种
- 体切片 alpha 传输函数可调（曲线编辑控件）
- 点云着色模式：径向距离 / 相位 / 概率密度 三选一
- 云质量预设增加描述性提示

### 6.4 渲染性能优化

- 实例化渲染：`glDrawArraysInstanced` 减少 draw call
- 视锥剔除：体切片只渲染可见部分
- 后台云构建在场景视口左下角显示进度环

## 8. 不变项

- 不改变 xmake 构建系统
- 不改变现有 OpenGL 3.3 Core 技术栈
- 不改变 Scientific Honesty 原则（所有方法标签和近似警告保持准确）
- 不改变现有测试框架和验证报告体系
- 不进行 Linux/macOS 适配
- 不引入新的外部依赖库（图表增强基于现有自绘系统）
